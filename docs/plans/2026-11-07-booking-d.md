## What the page is now
1. **The campaign band** (`.bk-band`, the `data-tg` section): title, the four teachers ringed in their day's color, the dancer on the pink disc. Hides itself the day after its last date, or once no campaign class is left to book. Its config list is the rule js/now.js and scripts/check-classes-jsonld.mjs already read (data-tg-date + data-tg-before), plus each morning's tone, the closed day, and each teacher's photo (`data-photo-<tone>` for a teacher on two days). Teachers are matched by the "with <Name>" in the Director's class name.
2. **One strip of class days** (`.bk-strip`): every open drop-in date in the two 21-day windows; a campaign's classes are ONE wide tile, picked on load while the campaign runs. Month labels, a pointer under the picked day, a pink dot on days already in the order. Sticky under the topnav. `?day=YYYY-MM-DD` (or `tg`) opens a day; `?class=<slug>` opens the class's first open date and outlines its row.
3. **One row per class** (`.bk-row`): Bebas time + length, face (campaign) or the dwdPS mark (weekly), class, teacher + Guest or "With the X team", age pill, price, Add. Weekly rows carry "Other Tuesdays" chips (same class_id + weekday + start time) so four weeks of one class is four taps. "Book 4 or more..." is said once per day, built from the feed's fee/bulk pairs.
4. **The order**: desktop aside (sticky), phone bar + sheet. Day-colored date tiles, x to remove, a four-step bar toward the bulk price (green once it applies, the site's own bulkNoteText wording), total, Check out.
5. **Checkout**: three numbered steps, same fields and rules. The summary uses the same order lines; it folds to one line on a phone. New: "Fits every class in this order" when the date of birth checks out.
6. **You're in**: a ticket per class in its day color with an Add to calendar `.ics` (studio time, TZID America/New_York), Before class, Book another dancer.

Unchanged code paths: the cart (localStorage key, 6-line cap, same-time clash), prices + bulk, pruneCart, the age warning + "Yes, book it anyway", the submit to drop-in-checkout, error copy, the Stripe return polling, the full ProSeries week grid.
